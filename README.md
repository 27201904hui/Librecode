# LibreCode

一款面向中文用户的本地智能体桌面应用（Windows x64），由民间开发者独立研发与维护。

## 这是什么

LibreCode 把「大模型对话、任务执行、浏览器自动化、工具调用」整合进同一个桌面。
支持接入本地模型与主流云端模型，目标是让不会写代码的普通人，也能在自己的
电脑上安全地使用 AI 智能体完成日常任务。

- 开箱即用：安装后即有完整内核，无需配置开发环境
- 本地优先：支持本地模型接入，数据留在自己的电脑上
- 工具能力：内置浏览器控制、屏幕理解、任务编排等智能体基础能力
- 中文友好：界面与文档均为中文
